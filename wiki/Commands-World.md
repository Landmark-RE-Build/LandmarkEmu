# Commands: World

> Generated by `tools/wiki_reference.py`. The world clock, trees and gathering, creatures in the open world, events. Back to [Command Documentation](Command-Documentation).

## Admin slash commands

The retail client's own commands, available to admins only (see [Who is an admin](Command-Documentation#who-is-an-admin)).

| Command | Who | What the server does |
|---|---|---|
| `/servertime (or /zonetime) hour <h> \| pause \| sync \| warp <rate>` | Admins | Moves, pauses or resumes, or changes the speed of the world clock, and re-syncs everyone online. |
| `/clienttime set \| hour \| pause \| sync \| warp \| advance \| reverse` | Admins | Changes only the admin's own client clock until its next time sync (the server echoes it back; unknown modes and NaN values are refused). |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `barrenrecipes` | `barrenrecipes [drop]` | Console / admins | Logs the twelve "Recipe: Barren …" items — built or not, prop, palette knowledge — for each player; "drop" leaves a loot bag at their feet with one they don't know, picked as a Barren kill picks it (BarrenRecipes.RandomUnknown, the chance roll skipped). |
| `clock` | `clock` | Console / admins | Shows the world clock in chat and in the log. |
| `composite` | `composite <effect id>` | Console / admins | Plays that composite effect on the player (as a hit impact does). |
| `eventexpire` | `eventexpire` | Console / admins | Dry run of the event island expiry (Landscapes.EventExpiry.cs): the setting, the island open now and at the last run, and every site on 460-462 with what happens to it (log; a summary in chat). eventexpire confirm &lt;zone&gt;: expires a closed island's sites now (design saved, terrain reverted, contents mailed; refused for the open island). |
| `fxat` | `fxat <effect> [metres] [ms]` | Console / admins | Plays a composite effect on the ground in front of the player (TargetLocation). |
| `outpostuse` | `outpostuse <n> chest\|crystal` | Console / admins | As if the player clicked that outpost's Lost Chest / Lost Crystal. |
| `outpostwake` | `outpostwake <n>` | Console / admins | Outpost n's crystal wakes, as when its Elite dies. |
| `pinata` | `pinata <definition> [kind] [a b c]` | Console / admins | A loot pinata 2 m ahead of the player. |
| `timeofday` | `timeofday <hour 0-24>` | Console / admins | Moves the world clock; everyone online is synced at once. |
| `treefall` | `treefall [u64 u32 u32 u32 u32 u32 f f f f]` | Console / admins | PlayerUpdate 0x2D Destroyed for the nearest tree. |
| `treepools` | `treepools` | Console / admins | The min / max pools of the player's landscape (most short of their minimum first). treepools fell &lt;n&gt;: fell n standing trees of the nearest tree's pool (no drops) to push it below its minimum; treepools now: make the landscape's queued respawns due (Gathering.Respawn.cs). |
