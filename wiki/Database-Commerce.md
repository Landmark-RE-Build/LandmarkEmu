# Database: Commerce (`lmemu_commerce`)

> Generated by `tools/wiki_reference.py`. Back to [Database Documentation](Database-Documentation).

The shared commerce service's own database (optional, compose profile `commerce`): Player Studio, contests, portraits and Showcase following for every world. Created by the service with plain SQL at start (no EF Core); columns added later are added at start when missing.

Source: `LandmarkEmulator.CommerceServer/CommerceStore.cs`. Code: [LandmarkEmulator.CommerceServer](Project-CommerceServer).

Tables: [`commerce_world`](#commerce_world), [`product`](#product), [`product_review`](#product_review), [`taken_design`](#taken_design), [`contest`](#contest), [`contest_entry`](#contest_entry), [`contest_vote`](#contest_vote), [`portrait`](#portrait), [`following`](#following), [`studio_payout`](#studio_payout), [`following_tag`](#following_tag), [`digest_run`](#digest_run), [`digest_mail`](#digest_mail), [`commerce_import`](#commerce_import)
