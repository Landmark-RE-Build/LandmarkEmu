# Commands: Server

> Generated by `tools/wiki_reference.py`. Running the server: shutdown, kicks, broadcasts, limits, the admin menu. Back to [Command Documentation](Command-Documentation).

## Admin slash commands

The retail client's own commands, available to admins only (see [Who is an admin](Command-Documentation#who-is-an-admin)).

| Command | Who | What the server does |
|---|---|---|
| `/target <name>  (also /gm target)` | Admins | Looks the character up (online or not) and sets it as the client's "admin target", which /goto, /profile and the /item commands then use. `/target clear` is handled by the client. |
| `/hideme [on\|off]` | Admins | Hides the admin from every other player (removed from their view, not introduced to arrivals, left out of /who) until `/hideme off`. |
| `/admin` | Admins | Opens the admin menu (a page in the in-game browser): give items, travel, building, time of day, creatures, shutdown, System Broadcast, kicks, the Player Studio staff queue, the server monitor and "Any command" (any dev command, for yourself, one player or everyone). Bound for admins when they enter the world. |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `broadcast` | `broadcast <text>` | Console / admins | A System Broadcast (BaseBroadcastPacket 0x4F, Game.Broadcasts) to the targets ("System Broadcast: &lt;text&gt;" on screen and in chat). "broadcast raw &lt;text&gt;" sends kind 0 (the text alone); "broadcast from &lt;Name&gt; &lt;text&gt;" a player broadcast ("Broadcast from &lt;Name&gt;: &lt;text&gt;"). |
| `friendtpcooldown` | `friendtpcooldown <seconds>` | Console / admins | Teleport to Friend's cooldown at run time (0 = none, as live since 5 May 2015; 1800 = the 2014 alpha's 30 minutes). Setting FriendTeleportCooldownSeconds. |
| `gc` | `gc` | Console / admins | Full compacting garbage collection (memory measurements), then the heap size. |
| `kick` | `@Name kick [seconds] [reason] \| @Name kick cancel` | Console / admins (needs `@Name`) | Removes that player (Game.Kicks): warnings (PendingKickFromServer 0x65 + a readable line) during the countdown, then KickedFromServer 0x53 and the connection closes. Needs "@Name": a bare "kick" would remove everyone. |
| `landscapecap` | `landscapecap <n> \| full \| config \| text <id>` | Console / admins | The travel queue's per-landscape limit at run time (0 = none; "full" queues every Travel-window arrival, for single-client tests), or the text of its "place free" Game Action Queue item. Prints the queue. |
| `maxplayers` | `maxplayers <n> \| full \| config` | Console / admins | The world's limit at run time, reported to the login server's queue with the next heartbeat (0 = no limit; "full" queues every login, for single-client tests). |
| `shutdown` | `shutdown <seconds> [message] \| shutdown cancel` | Console / admins | The server shutdown countdown (Game.Shutdown). |
