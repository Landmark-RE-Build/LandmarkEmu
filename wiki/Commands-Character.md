# Commands: Character

> Generated by `tools/wiki_reference.py`. Your character: health, stats, movement, achievements, appearance. Back to [Command Documentation](Command-Documentation).

## Admin slash commands

The retail client's own commands, available to admins only (see [Who is an admin](Command-Documentation#who-is-an-admin)).

| Command | Who | What the server does |
|---|---|---|
| `/run <n> \| /run inc <n> \| /run dec <n> \| /run default` | Admins | Sets the admin's movement speed in metres per second (default 12) and re-sends the stats; `default` (or 0) removes the override. |
| `The client's grief admin commands (set damage level, set grief level, reset)` | Admins | Act on the admin themselves: set the grief damage points or level (1-3 warnings, 4 weapon lock, 5 suspension) or clear it. Saved with the character. The exact command words are the client's and are not listed here. |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `achreset` | `achreset <achievement id>` | Console / admins | Back to not started (tests that complete an achievement). |
| `anim` | `anim <AnimationSelection id> [dx dz]` | Console / admins | Play an animation on the player (emote testing), turning them towards their position + (dx, 0, dz). |
| `calcstats` | `calcstats` | Console / admins | Logs the calculated stats the server sends the player (non-default ones). |
| `cancelbuff` | `cancelbuff <buff name>` | Console / admins | As the buff bar's cancel button for that buff. |
| `charstats` | `charstats [on\|off]` | Console / admins | The live character stats; "on" also sends them to the targeted players now. |
| `clearunlocks` | `clearunlocks <kind>…` | Console / admins | Forget the player's unlocks of those kinds (Unlocks.*; test). |
| `emotelead` | `emotelead <ms>` | Console / admins | How long after putting a held tool away an emote is played (EmoteHolster.PutAwayLead). |
| `fte` | `fte <id>` | Console / admins | Show a first-time event (if not seen yet); fte clear: forget every seen event. |
| `god` | `god on\|off` | Console / admins | The player takes no damage (tests with hostile creatures). |
| `grief` | `grief level <n> \| points <n> \| damage <n> \| award <damage> \| show \| reset` | Console / admins | Level / points / damage set the state (GriefBase 2 / 1), award &lt;damage&gt; counts that much damage to an ally as a friendly-fire hit would (even with GRIEF_AWARDS off), show makes the client print the points it holds (GriefBase 1 with -1, -1), reset clears everything. |
| `hurt` | `hurt <hp>` | Console / admins | Damage the player (death at 0). |
| `movement` | `movement` | Console / admins | The player's open channel (sprint, Immediate Delivery, Endless Breeze), charging leap and movement-ability cooldowns; Energy is in "states". |
| `movementeffects` | `movementeffects on\|off` | Console / admins | Sprint / boot caster-info replies with or without their client-run movement effects. The client keeps replies it has until relog. |
| `objective` | `objective <id> [amount]` | Console / admins | Counts towards an achievement objective (goals testing). |
| `portraittest` | `portraittest <character> <Headshot\|Portrait> <image set id>` | Console / admins | Store an exported icon as that character's image and send it to the player (tests the client's portrait display). |
| `pos` | `pos` | Console / admins | The player's position (local metres), landscape and the surface height there. |
| `resettitles` | `resettitles` | Console / admins | Forget every title the player owns or shows (test). |
| `respawn` | `respawn [type]` | Console / admins | Answers the death window for the player (10 here, 11 safe point). |
| `revive` | `revive` | Console / admins | A dead player is alive again with full health where they stand (tests). |
| `reviveby` | `reviveby <dead player>` | Console / admins | As if the player cast the revive (246) at them (the 0.589 UI can't reach that cast; see Health.ReviveBy). |
| `safeeject` | `safeeject [clear\|on\|off]` | Console / admins | The launches reported (SafeEject 0x26/0x4C) and not ended yet, in the log; clear = end the targeted players' launches now (bit 26 cleared); on / off = the setting SafeEjectReset until the restart (Game/SafeEject). |
| `setres` | `setres <resource id> <type> <value>` | Console / admins | Sets one of the player's resource pools on their client (19 2 = Energy, 13 10 = Stamina, 4 1 = Life), as SetCharacterResource does. |
| `weartint` | `weartint <alias>` | Console / admins | Re-send the player's own worn outfit / armour slots with another tint alias (this client only, nothing saved) — to see which ArtTints alias gives which colour. "weartint" alone re-sends the items' own tints. |
