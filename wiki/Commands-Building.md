# Commands: Building

> Generated by `tools/wiki_reference.py`. Build sites, props, designs (templates), copy and paste. Back to [Command Documentation](Command-Documentation).

## Admin slash commands

The retail client's own commands, available to admins only (see [Who is an admin](Command-Documentation#who-is-an-admin)).

| Command | Who | What the server does |
|---|---|---|
| `/prop <prop id>` | Admins | Places a free prop at the point under the crosshair, owned by the admin, saved and shown to the landscape. |
| `/prop reset_zone_and_wipe_db_forever_with_no_undo` | Admins | Refused, and logged with who tried. |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `beginclaim` | `beginclaim` | Console / admins | Puts the client into build-site placement, as using a Build Site Flag does. |
| `beginprop` | `beginprop <prop id>` | Console / admins | Starts a placement as if picked from the props palette; beginprop #&lt;item id&gt;: as if placing that prop item from the bag (the player needs one; opens build mode as the bag does, BuildModeHolster.OpenForPlacement). |
| `claimbasic` | `claimbasic` | Console / admins | Re-sends the landscape's SendAllClaimBasicInfo (as answering 0x19 does). |
| `claimhere` | `claimhere` | Console / admins | Claims a build site at the player (gives the flag, then request + confirm). |
| `claims` | `claims` | Console / admins | Sends the player every build site of the landscape again. |
| `clearprops` | `clearprops` | Console / admins | Removes all of the player's props, no refund (test clean-up). |
| `copyhere` | `copyhere <voxels>` | Console / admins | Copies the props in a box of that many voxels around the player (Building.DevCopy). |
| `designoffer` | `designoffer <design guid hex>` | Console / admins | As "Get Resources Now" (TemplateBase 0x1D): the missing materials offer. |
| `ensureclaim` | `ensureclaim` | Console / admins | As `claimhere`, but only for players without a build site (for tests that need one). |
| `expiresites` | `expiresites all \| <site id> …` | Console / admins | Expires those build sites as upkeep expiry does (removed for everyone, a design saved, the terrain reverted, props and resources mailed to the owner). Deletes builds: back up first. |
| `exportdesign` | `exportdesign <design guid>` | Console / admins | As the Designs window's export to item (TemplateBase 0x1B). |
| `giveprop` | `giveprop <prop id>` | Console / admins | One item that places that prop. |
| `grantaccess` | `grantaccess <player> <hex mask>` | Console / admins | Special Access for a player on this player's own site (0 = No Touching, 80000000 removes it as Site Management's delete does; 11F = Ultimate). |
| `lapsesite` | `lapsesite` | Console / admins | The player's build site lapses now (upkeep run out): reverted, props packed. |
| `launch` | `launch <prop hex>` | Console / admins | Launches a Fireworks Emitter for the players in its zone (as its Link action). |
| `offgridpaste` | `offgridpaste <yaw degrees> [design guid]` | Console / admins | The off-grid paste (VoxelConstruction 0xF4 sub 5) of the clipboard (or a design) with its corner 2 m in front of the player, turned by that yaw (Building.DevOffGridPaste). |
| `paletteslot` | `paletteslot <slot> <type> <value>` | Console / admins | As the radial menu's AddEntry. |
| `pasteat` | `pasteat dx dy dz` | Console / admins | Pastes the clipboard with its corner at that offset from the player. |
| `pioneer` | `pioneer` | Console / admins | The new-player start for an existing character without a site. |
| `pioneerslab` | `pioneerslab` | Console / admins | Test aid. Queues the slate slab under each target's own site on the Pioneer land they stand on, as a new Pioneer site gets it (once per site: a site that has it is left alone). |
| `placeat` | `placeat x y z [yaw]` | Console / admins | Finishes the pending placement there through the normal Save. "placeat here [yaw]": at the player's feet. |
| `placedesign` | `placedesign <design guid>` | Console / admins | Places the design 2 m in front of the player (test of design paste). |
| `prop` | `prop <prop id> [dx dy dz]` | Console / admins | Places that prop next to the player (default 2 m along x) as a placed prop. |
| `propcost` | `propcost <prop id>` | Console / admins | What placing the prop costs this player. |
| `propdelete` | `propdelete <guid>` | Console / admins | Delete one of the player's placed props (cleans up after tests). |
| `propenable` | `propenable <guid hex> <0\|1>` | Console / admins | Switch a placed prop's light/effect as if from the prop menu. |
| `propmenu` | `propmenu <guid hex\|near>` | Console / admins | Runs the server side of a right-click on a prop (RadialMenuRequest {guid, 1}) — the prop menu answer and, in build mode, the prop's name over it (Props.MenuName.cs). The client shows no menu, but the label shows and goes after 10 s or the next prop request. "near" = the nearest placed prop within 20 m. |
| `propmove` | `propmove <guid hex> dx dy dz` | Console / admins | Opens an edit session on a placed prop (PropAccess) and saves it moved by the offset, as the placement gizmo does (tests prop-move undo). |
| `propname` | `propname <prop hex> <name>` | Console / admins | As the prop menu's rename (PropBase 0x19). |
| `propread` | `propread <prop hex>` | Console / admins | As using a sign / book / scroll with text (Props.Read). |
| `propremove` | `propremove <guid>` | Console / admins | Delete a placed prop (no player needed, no refund). |
| `propset` | `propset <prop hex> <setting key> <value>` | Console / admins | As the prop's settings window. |
| `propshowtext` | `propshowtext <prop hex> <mode> [seconds]` | Console / admins | Shows a prop's text as Links would (Props.DisplayText). |
| `propstream` | `propstream [<metres>\|off]` | Console / admins | With a value, the placed-prop stream range (setting PropStreamRange; off / 0 = the whole landscape) until the restart, applied on each player's next stream tick; then (or alone) each targeted player's stream in the log (Props.Stream.cs). |
| `proptext` | `proptext <prop hex> <text>` | Console / admins | As the sign / Story Node text editor. |
| `proptint` | `proptint <guid> [alias]` | Console / admins | Set or clear a placed prop's tint (no player needed). |
| `psinstances` | `psinstances [clear]` | Console / admins | The placed Player Studio designs recorded on the player's current site (visitors can't copy over them, TemplateInstances); clear drops those records. |
| `sitemusic` | `sitemusic <ClaimMusic id>` | Console / admins | As Build Site Management's music list for the player's own site. |
| `sitename` | `sitename <name>` | Console / admins | Renames the player's site (same checks as Build Site Management). |
| `unclaim` | `unclaim` | Console / admins | Abandons the player's build site, as Build Site Management's abandon does. |
| `undo / redo` | `undo / redo` | Console / admins | As Ctrl+Z / Ctrl+Y (VoxelConstruction sub 3). |
