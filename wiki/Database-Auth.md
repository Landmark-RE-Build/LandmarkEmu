# Database: Auth (`lmemu_auth`)

> Generated by `tools/wiki_reference.py`. Back to [Database Documentation](Database-Documentation).

Accounts and the server list. Shared by every world. Used by the login server (AuthServer, its web API) and read by the worlds and gateways for the login checks.

Source: `LandmarkEmulator.Database.Auth/Migrations/AuthContextModelSnapshot.cs` and the model classes in `LandmarkEmulator.Database.Auth/Model`. Code: [LandmarkEmulator.Database.Auth](Project-Database-Auth).

Tables: [`account`](#account), [`admin`](#admin), [`zone_server`](#zone_server)
