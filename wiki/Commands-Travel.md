# Commands: Travel

> Generated by `tools/wiki_reference.py`. Teleports, landscapes, the Spire, Chaos Caverns and outposts. Back to [Command Documentation](Command-Documentation).

## Admin slash commands

The retail client's own commands, available to admins only (see [Who is an admin](Command-Documentation#who-is-an-admin)).

| Command | Who | What the server does |
|---|---|---|
| `/goto <name>  (also /goto player <name>, /warp)` | Admins | Teleports the admin beside an online player (partial names work), changing landscape when needed. |
| `/goto waypoint [name]` | Admins | Logged only: the server keeps no player waypoints yet. |
| `/location <x> <y> <z> [heading], the camera teleport, the world map's admin teleport` | Admins | Moves the admin to the exact point (TeleportToLocation). The same handler serves the Escape menu's Evac to Safety for everyone. |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `cave` | `cave [zone]` | Console / admins | The same as Travel -&gt; An Underground Adventure (a random cavern graveyard; with a zone, one of that landscape's, outposts placed or not; a cavern while its graveyards aren't ready). |
| `cavetrip` | `cavetrip <crystal\|adventure> [client world id] [zone]` | Console / admins | A Lost Crystal / Underground Adventure trip to another world of the gateway now, whatever the roll and CavernTripsOtherWorlds say (default: the first reachable world, a random Chaos Cavern landscape). That world picks the cavern as for a real trip. |
| `chest` | `chest [go\|open]` | Console / admins | The nearest treasure chest; "go" walks there, "open" opens it. |
| `drop` | `drop <metres>` | Console / admins | Teleport straight up without snapping to the ground (fall tests). |
| `graveyard` | `graveyard [go] [cavern\|surface]` | Console / admins | The landscape's graveyards (counts, the player's layer, whether they stand in a buffer zone) and the nearest one of their layer (or the named one); "go" moves the player to its arrival point. |
| `landscape` | `landscape <zone id>` | Console / admins | Travel there (same as choosing it in the Landscapes window; also a closed event island 460-462, e.g. to bake its heights). |
| `landscapes` | `landscapes` | Console / admins | Sends the Other Worlds list (the client opens the Travel window on it). |
| `outpost` | `outpost <n>` | Console / admins | Go to outpost n (Chaos Caverns), next to its middle. Home continent 0-80; another landscape 128 × (zone - 390) + k (cavelands lists them), re-zoning there. |
| `spire` | `spire` | Console / admins | The same as casting the Spire travel ability. |
| `terminal` | `terminal <hub \| c<index> \| hex node> [open 0/1]` | Console / admins | TeleportBase ActivateTerminal, as if the player used that portal crystal (hub and c&lt;index&gt;: of the player's own landscape). |
| `tp / tpo` | `tp x y z [nosnap] (local metres) / tpo dx dy dz (relative)` | Console / admins | ClientUpdate 0xC TeleportToLocation. "nosnap" keeps the exact height (e.g. inside a cave) instead of dropping onto the surface. |
| `tpclaim` | `tpclaim` | Console / admins | To the middle of the player's own build site. |
| `tpto` | `tpto <character>` | Console / admins | To another player's landscape and position (two-player tests). |
| `tpz` | `tpz x y z` | Console / admins | Teleport through a re-zone (loading screen), like long jumps. |
| `tree` | `tree [dx dz [plant]]` | Console / admins | Stand next to the nearest standing tree or plant (default 2.5 m on its -x side). |
