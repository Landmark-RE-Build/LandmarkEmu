# Commands: Commerce

> Generated by `tools/wiki_reference.py`. The Showcase store, Player Studio, contests, membership, vendors. Back to [Command Documentation](Command-Documentation).

## Player commands

| Command | Who | What it does |
|---|---|---|
| `/membership` | Everyone | Shows your membership and the offer. |
| `/membership buy` | Everyone | Buys MEMBERSHIP_DAYS days of membership for MEMBERSHIP_PRICE_LUMENS Lumens (not offered when the price is 0). |
| `/membership grant <name> <days>` | Admins | Adds days of membership to an online player's account. |
| `/membership revoke <name>` | Admins | Ends an online player's membership. |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `contestenter` | `contestenter <contest name>` | Console / admins | As the Contest window's Enter for the player's site. |
| `contestphase` | `contestphase <id> entries\|voting\|judging` | Console / admins | Moves a contest's dates so it is in that phase now. |
| `contests` | `contests` | Console / admins | Lists the contests and their phases in chat. |
| `followdigest` | `followdigest [dry] [hours]` | Console / admins | Runs the Showcase following digest now (Game.ShowcaseFollow): the mails for what was listed since the last run (or the last &lt;hours&gt;); "dry" composes them only (nothing sent, no run recorded) and shows each one to the players named. Runs whether or not SHOWCASE_FOLLOW_DIGEST is on. |
| `psfee` | `psfee [price]` | Console / admins | Re-sends Player Studio's CommerceConfiguration 0x2E and the wallet, and logs the listing fee for that price (default 25), the wallet balance sent and the player's own designs' minimum prices (TemplateValue). Test tooling for the listing fee (Game.Commerce.SendConfiguration). |
| `psoffer` | `psoffer` | Console / admins | Sends the product-for-review reply now (test tooling; the client asks at login). |
| `psreview` | `psreview <product id> approve\|reject` | Console / admins | Decides a Player Studio product (Game.Commerce). |
| `pstake` | `pstake <product id>` | Console / admins | Buys a listed Player Studio design as the Showcase's Buy / Get does (its price in Lumens unless FreeStore; the creator is mailed their share). Test tooling for the page's POST /api/studio/take. |
| `storespent` | `storespent [lumens]` | Console / admins | Shows (or sets) the Lumens this character spent on the store and Player Studio (Unlocks kind 33), and whether the account may peer-review (Commerce.MayReview, live's 1000 SC rule). |
| `storetoken` | `storetoken` | Console / admins | Log the player's Showcase token (tests call the store's web API with it). |
| `studiotake` | `studiotake <product id>` | Console / admins | The Showcase's Player Studio "Get" without the browser (tests). |
| `vendoropen` | `vendoropen <vendor guid hex>` | Console / admins | As if the player clicked that build site vendor. |
