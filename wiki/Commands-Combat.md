# Commands: Combat

> Generated by `tools/wiki_reference.py`. Weapons, creatures, combat states and creature pathing. Back to [Command Documentation](Command-Documentation).

## Admin slash commands

The retail client's own commands, available to admins only (see [Who is an admin](Command-Documentation#who-is-an-admin)).

| Command | Who | What the server does |
|---|---|---|
| `The build tool "PathFindVisualize" (two clicks)` | Admins | Runs the server's creature pathing between the two points and answers in chat (straight-line verdict, reached / partial / none, waypoints, length). The retail client has no palette entry for the tool; the dev command `pathquery` sends the same request. |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `attackinfo` | `attackinfo [ids]` | Console / admins | How weapon casts are classified (kind, damage ×, Energy cost). |
| `blockstances` | `blockstances` | Console / admins | The blocking stances up now (guid, arc, end, clients told), in the log. |
| `blockvisible` | `blockvisible on\|off` | Console / admins | Blocking stances shown to the other clients or not until the restart; stances already shown still end normally. |
| `casterinfo` | `casterinfo <ability>` | Console / admins | Sends that item ability's CasterInfoReply unasked (what the client gets when it asks because the item is held), e.g. to check the sickle's arc in a test. |
| `clearcreatures` | `clearcreatures [radius]` | Console / admins | Kills creatures near the player (they respawn later). |
| `creature` | `creature <kobold\|runt\|shaman\|skeleton\|slaug\|ogre> [dx dz]` | Console / admins | A hostile creature near the player. |
| `creatures` | `creatures` | Console / admins | Writes the creatures around the player to the server log. |
| `creatureweapon` | `creatureweapon <creature guid hex \| near> <Wield_*.adr \| off> [tint alias]` | Console / admins | Puts a weapon actor in a creature's main hand, whatever CreatureWeapons is set to. "near" = the creature nearest the command's player (30 m). |
| `fire` | `fire [power]` | Console / admins | The held weapon's Basic / Power attack straight ahead (no input; WeaponCombat). |
| `hitnear` | `hitnear <damage>` | Console / admins | The nearest creature takes a hit from this player. |
| `kobold` | `kobold [dx dz]` | Console / admins | A hostile kobold next to the player. |
| `meleetargeters` | `meleetargeters on\|off` | Console / admins | Melee weapon replies with or without their client Sweep targeter; the targeted players get their attack info again. |
| `npc` | `npc <model> [dx dz]` | Console / admins | Spawn a creature model next to the player (visual test). npc reload | goto &lt;id&gt; | reset | flag &lt;id&gt; &lt;key&gt; [value]: world NPC scripting helpers. |
| `pathing` | `pathing [on\|off]` | Console / admins | Creature navigation — the walkable floors at the player's spot and each creature within 40 m (nav kind, straight line to the player, path), logged; on / off switches it until the restart (setting CreaturePathing). |
| `pathquery` | `pathquery dx dy dz` | Console / admins (the target must be an admin) | The PathFindVisualize tool's DebugPathQueryRequest (0x1E / 0x4A7) from the player to that offset, answered in chat (AdminCommands.DebugPathQuery; admins only, as from the client). |
| `projectile` | `projectile <definition> [distance] [speed]` | Console / admins | Projectiles fly at the player from N / S / E / W; Delete at arrival. speed 0 = the definition's own. |
| `sight` | `sight` | Console / admins | Line-of-sight check of the creatures near the player (Game/Sight.cs), logged. |
| `sitepathing` | `sitepathing [on\|off]` | Console / admins | Story creatures' build-site navigation — every site / dug outpost grid held, logged; on / off switches it until the restart (setting SitePathing). |
| `slay` | `slay [radius]` | Console / admins | The nearest creature dies as if this player killed it (loot bag, goals). |
| `states` | `states` | Console / admins | Combat states on the player and the creatures within 25 m. |
| `status` | `status <name> [seconds]` | Console / admins | Puts a combat status on the player (Combat.Status, e.g. Eruption so the next fire hits erupt, which is otherwise a 15 % roll). |
| `struck` | `struck [damage] [count]` | Console / admins | The nearest creature (30 m) hits this player [count] times through the normal path (blocks, Harden, shields, the armour's defensive passives: Crashing Waves, Frost Lord's Guard, Harden explosions …; each passive that fires logs "&lt;name&gt; passive: …"). |
| `weaponattack` | `weaponattack basic\|charged\|power\|special [times]` | Console / admins | The held weapon's attack at the nearest creature (Combat.WeaponCombat); "charged" is the basic attack fully charged (held), as the client's charged cast ends; "special" is an E cast (the kit's Special, else its Power attack). |
