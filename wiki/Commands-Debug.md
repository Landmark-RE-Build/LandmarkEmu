# Commands: Debug

> Generated by `tools/wiki_reference.py`. Developer probes and test switches. Not needed to run a server. Back to [Command Documentation](Command-Documentation).

## Player commands

| Command | Who | What it does |
|---|---|---|
| `/gatewayprofiler on \| off \| dump` | Everyone (own connection only) | Counts this connection's packets by kind and direction and prints them as system lines (the gateway's own command; live's was an admin tool). |

## Admin slash commands

The retail client's own commands, available to admins only (see [Who is an admin](Command-Documentation#who-is-an-admin)).

| Command | Who | What the server does |
|---|---|---|
| `/setmodel id` | Admins | Shows you (or your admin target) as that model to everyone on the landscape until `/setmodel 0` or a relog. |
| `/vehicle, /ammo, /weaponset, /placedeffect, free-fly hide, /profile …` | Admins | Decoded and logged with their fields; the systems behind them (vehicles, ammo, weapon sets, placed effects, job profiles) are not built. |
| `Admin monitor requests (pathing data, zone player count, Storybricks diagnostics)` | Admins | Logged at most once a minute per admin and kind; the retail client never sends them and has no reader for a reply. |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `abilitystats` | `abilitystats` | Console / admins | The abilities the captured item definitions name (distinct ids, by type and input). |
| `ambients` | `ambients` | Console / admins | Items whose definition carries an ambient composite effect. |
| `blockcell` | `blockcell <level> <x> <y> <z> <x0> <y0> <z0> <x1> <y1> <z1> [material] [layer] [prefixSize]` | Console / admins | Push a voxel box as block data (live). |
| `blockdmg` | `blockdmg <level> <x> <y> <z> <firstBlock> <lastBlock> <health%>` | Console / admins | Probe CellBlockDamage on real terrain. |
| `caveair` | `caveair <gx gy gz> (global dm)` | Console / admins | Is the client's generated world cave air there? |
| `cellcompare` | `cellcompare on\|off` | Console / admins | Log how the stored cell compares with each edit's cell, and whether a selection Delete / Cut's client layer versions name the server's result (Building.CompareWithClient). |
| `digmode` | `digmode <n>` | Console / admins | How digs shape holes (TerrainEdits.OffsetMode): 8 the client's own surface (default), 5 the old solid shell, 0 no vertices. For side-by-side checks. |
| `durability` | `durability <item def> <value>` | Console / admins | Sends a carried item's consumed-count field (the client calls it ConsumedCount, not durability). Test only. |
| `gamelabels` | `gamelabels [off]` | Console / admins | Switches the labels over site-game control points on or off. |
| `guildpacket` | `guildpacket <sub hex> <body hex>` | Console / admins | Handle a GuildBase request as if the player's client sent it (tests the roster's right-click requests, which can't be driven through client Lua). |
| `harvestfail` | `harvestfail <reason> [resource]` | Console / admins | The client's harvest failure message (Gathering.HarvestFail). |
| `isair` | `isair [n]` | Console / admins | Cave air (CavePieces.IsAir) on a vertical line through outpost n's floor middle, every 4 m. |
| `itemslot` | `itemslot <equipment slot id>` | Console / admins | Up to 30 item definitions worn in that slot (8 = chest armour). itemslot &lt;slot&gt; [model text]: optionally only models containing the text (e.g. _Bow_). |
| `lastmove` | `lastmove` | Console / admins | Writes the player's last full movement packet to the log. |
| `livecell` | `livecell <level> <x> <y> <z> [height] [variant]` | Console / admins | Change a cell while players are in the world, pushed as a block event (damage + CellsUpdate naming the same transaction). |
| `loot / content` | `loot reload \| content reload` | Console / admins | Reload ContentTables (baked + /data/content) without a world restart. |
| `lua` | `lua <Table:Function or Table.Function> [a b c]` | Console / admins | Runs a Lua function of the player's game client with up to three numbers. It reaches only the admin who runs it and other admins, and may not name a function that opens the player's desktop web browser, unless DEV_CLIENT_CODE_ON_OTHERS is true. Every use is logged. |
| `luacode` | `luacode <Lua code>` | Console / admins | Runs a line of Lua code in the player's game client. Same limits as `lua`. |
| `luas` | `luas <Table.Method> [arg arg...]` | Console / admins | Calls a Lua function of the player's game client with text arguments. Same limits as `lua`. |
| `mailpacket` | `mailpacket <sub hex> <body hex>` | Console / admins | Handle a MailBase request as if the player's client sent it (tests compose, whose window object client Lua can't build). |
| `npcmode` | `npcmode <n>` | Console / admins | Creature spawn control mode for later spawns (0 = client ignores positions). |
| `observed` | `observed <operation> [size m]` | Console / admins | Sends the player a ResponseObserved (another player's edit effect, Building.SendObserved) for a box of that size 3 m in front of their feet. |
| `pinatafor` | `pinatafor <item> [item…]` | Console / admins | The loot chunk model each resource item drops (LootPinata.txt id). |
| `portraitcrc` | `portraitcrc <crc hex>` | Console / admins | As if the client sent AddClientPortraitCrc (tests the upload check). |
| `propslide` | `propslide <guid hex> dx dy dz [seconds]` | Console / admins | Sends a movement for a placed prop towards its spot plus the offset, to see whether the client moves a placed prop that way. The server's record is unchanged. |
| `rezonecave` | `rezonecave` | Console / admins | Test only. A random cavern through Teleport.Rezone (ClientBeginZoning). |
| `rimmode` | `rimmode <n>` | Console / admins | Test switch for how the rim of a dug hole is smoothed. |
| `ringscale` | `ringscale <scale>` | Console / admins | Scales the gathering tools' harvest area and re-sends the player's calculated stats. |
| `send` | `send <hex bytes>` | Console / admins | Sends a raw zone packet, opcode bytes included, to the player. For protocol tests only; same limits as `lua`. |
| `slotitems` | `slotitems <equip slot id>` | Console / admins | Item definitions for that equipment slot (1 outfit, 2 main hand, 3 accessory, 4 feet, 5 hook, 8 chest). |
| `spirefull` | `spirefull [off]` | Console / admins | Sends the Spire props' full data at once instead of waiting for the client to ask. |
| `stampdry` | `stampdry [n]` | Console / admins | Counts outpost n's template voxels as the stamp sees them (air / cave air), writes nothing. |
| `stream` | `stream` | Console / admins | Why surface objects are (not) streaming to each player. |
| `sysmsg` | `sysmsg id <text id> [name=value...] \| sysmsg key <key or text> \| sysmsg chan7 <text>` | Console / admins | PacketShowSystemMessage / a channel-7 chat line, to compare what the client shows. |
| `testcell` | `testcell <level> <x> <y> <z> [height 0-65535] [extent] [variant]` | Console / admins | Replaces one terrain cell with a flat test mesh and sends it to the players (terrain format tests). |
| `uievent` | `uievent <id>` | Console / admins | As if the client reported UIEventTriggered &lt;id&gt; (goal hooks, first-time help). |
| `veintest` | `veintest` | Console / admins | The vein port against fixed inputs (compare with the Python reference). |
| `weaponkeywords` | `weaponkeywords [off]` | Console / admins | Test switch: send weapon keywords with weapon attack info or not. |
| `whoami` | `whoami` | Console / admins | Writes the player's guid, landscape, position and target to the log. |
