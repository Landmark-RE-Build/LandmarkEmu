# Commands: Items

> Generated by `tools/wiki_reference.py`. Items, inventory, equipment, crafting, chests and loot. Back to [Command Documentation](Command-Documentation).

## Admin slash commands

The retail client's own commands, available to admins only (see [Who is an admin](Command-Documentation#who-is-an-admin)).

| Command | Who | What the server does |
|---|---|---|
| `/item add <item> [count] [tint] [name\|guid]` | Admins | Gives items to the target (the named player, else the admin target, else the admin). Tints are reported but not kept. |
| `/item delete <item guid> [name\|guid], /item undelete <item guid> [name\|guid]` | Admins | Deletes a stack; undelete gives it back while the world keeps running. |
| `/item list [name\|guid]` | Admins | Lists every stack of the target's, by container, in chat. |
| `/item check <item> [name\|guid]` | Admins | Tells how many of that item the target has, and where. |
| `/item random <item> [catalyst] [count]` | Admins | Gives the item itself (this server's items have no rolled variants). |
| `/item vault \| unvault \| collect \| uncollect \| vaultcollect \| vaultuncollect \| overflow \| unoverflow \| buyback \| unbuyback <item> [name\|guid]` | Admins | Moves the item's stacks between the bag and that container. Buyback and the vault collection have no storage in the 0.695 client, so those two are refused with the reason. |

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `abilities` | `abilities [item...]` | Console / admins | The abilities (id, type, input, category) of item definitions; without arguments, of every item that has any (to the log). |
| `activate` | `activate <item id>` | Console / admins | Uses one held item as the bag's Use does (recipe items, storage expansions, unlockers, prop placement). |
| `autoresupply` | `autoresupply <item def> [on\|off]` | Console / admins | The auto-resupply switch of the player's first stack of that kind, as the client's CoinStoreScreen.TurnOn/OffAutoResupply(def) picks it (Inventory 0x2D sub 0x0D), without the client's definition check, which no live definition passes. Saved; the client sees it in the item record at the next login. Without on / off it only logs the switch of every stack of that kind. |
| `cancelcraft` | `cancelcraft` | Console / admins | As the client's RecipeBase 3 CancelRequest. |
| `chestopen / chestput / chestpickup` | `chestopen` | Console / admins | Open the nearest chest (EnableWindow, as a click does). chestput &lt;item&gt; &lt;n&gt;: put items into the nearest chest. chestpickup: Picks up the nearest storage chest, as the prop menu does. |
| `closecraft` | `closecraft` | Console / admins | The server closes the target's crafting / repair window (RecipePacketZoneCraftingWindow 0x42/0x24 with bool 0, Crafting.CloseWindow), as walking away from the station does. |
| `coins` | `coins <+n\|-n\|=n>` | Console / admins | Gives, takes or sets coins. |
| `combatgear` | `combatgear` | Console / admins | CombatGear.txt — every weapon / combat item with its abilities (id, type, input, category). |
| `craft` | `craft <recipe> <count>` | Console / admins | Start a craft at the open station, as the client's Start request. |
| `durabilityof` | `durabilityof <item def>` | Console / admins | Wear and condition of the player's items of that kind. |
| `equipped` | `equipped` | Console / admins | Each equipped item with its definition's slot, model and categories. |
| `finditem` | `finditem <text\|#id>` | Console / admins | Item definitions whose name contains the text (as this client names them), or by id. |
| `founderchest` | `founderchest` | Console / admins | As using the Spire's Founder's Chest (missing Founder's Pack items back). |
| `give` | `give <item id> <count>` | Console / admins | Gives items to the player (into the bag; what does not fit goes to overflow). |
| `giveoverflow` | `giveoverflow <item> <count> [minutes]` | Console / admins | Puts items straight into overflow (tests of "Retrieve all"); minutes: they expire that soon instead of after OverflowExpiryHours (OverflowExpiry). |
| `itemaudit` | `itemaudit` | Console / admins | ItemAudit.txt (what each item does on this server; unhandled abilities first). |
| `iteminfo` | `iteminfo <id>…` | Console / admins | Model, image set, tint of item definitions. |
| `itemstats` | `itemstats on\|off` | Console / admins | Tool stats in item records (from the next item sent / login). |
| `lootbag` | `lootbag <item> [count]` | Console / admins | A loot bag at the player's feet (pickup → loot toast). |
| `lootfree` | `lootfree <item> [count]` | Console / admins | One OWNERLESS loot bag 3 m ahead of the first target, shown to every player on that landscape within 50 m; the first to come within 5 m claims it (NotifyOwnerlessLootClaimed to all), and only the claimer's client picks it up. |
| `resupply` | `resupply` | Console / admins | As using the Spire's Resupply Chest (missing starter tools back). |
| `setwear` | `setwear <item def> <wear points>` | Console / admins | Wear the player's carried items of that kind. 0 = as new. |
| `sortbag` | `sortbag` | Console / admins | Reverses the bag's order the way the window's sort sends it (RearrangeItemSlots). |
| `station` | `station <station id>` | Console / admins | Opens that crafting station's window wherever the player is. |
| `take` | `take <item> [count]` | Console / admins | Removes items (all of them without a count). |
| `unwield` | `unwield [equipment slot]` | Console / admins | Puts the item in that slot back in the bag (default 2, the main hand). |
| `use` | `use <item id>` | Console / admins | Use one of that item as its ability would (consumables: potions, gadgets). |
| `vault` | `vault [variant]` | Console / admins | Opens the vault window (Command 0x1E sub 0x50 InteractionVault {…, u64 entity}). |
| `vaultnear` | `vaultnear` | Console / admins | Uses the nearest vault prop within 6 m (as clicking it does). |
| `weapons` | `weapons` | Console / admins | Item definitions with abilities that aren't gathering tools (what HeldWeapon accepts). |
| `wield` | `wield <item>` | Console / admins | Gives the item if missing and equips it (weapons: main hand). |
