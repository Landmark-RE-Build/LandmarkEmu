# Commands: Games

> Generated by `tools/wiki_reference.py`. Site games (instanced games) and the story tools. Back to [Command Documentation](Command-Documentation).

## Dev commands

Run from `dev_commands.txt` or the admin menu's *Any command* (see [Running dev commands](Command-Documentation#running-dev-commands)). "Console / admins" = the server owner through the file, or an admin.

| Command | Syntax | Who | What it does |
|---|---|---|---|
| `finderwaiting` | `finderwaiting <table guid hex> [off] \| off` | Console / admins | This world publishes that game to the shared Game Finder as if someone were waiting in it. |
| `game` | `game` | Console / admins | The site game here (or the player's) and its players; "game rules": the rule sets. |
| `gameedit` | `gameedit [off]` | Console / admins | Opens (closes) the client's game editor for the site's game, as the client's Claims.RequestGainActiveAuthorshipOfGame does. |
| `gameend` | `gameend` | Console / admins | Ends the running site game round now. |
| `gamejoin` | `gamejoin` | Console / admins | Joins the site game the player stands in. |
| `gameleave` | `gameleave` | Console / admins | Leaves the site game. |
| `gamepoint` | `gamepoint` | Console / admins | Describes the site game's control points in chat. |
| `gamescore` | `gamescore <points>` | Console / admins | Adds points to the player's score in the running site game. |
| `gamestart` | `gamestart` | Console / admins | Start the round now (no minimum players, no countdown). |
| `gametp` | `gametp [off]` | Console / admins | Switches the site games' spawn teleports on or off. |
| `npctext` | `npctext <mode> <text>` | Console / admins | DisplayPropText spoken by the nearest creature. |
| `playmode` | `playmode on\|off` | Console / admins | As the Play Mode button for the site the player stands on. |
| `story` | `story` | Console / admins | Describes the story-tool setup around the player (story props, links, creatures) in chat. |
| `storyclick` | `storyclick <guid hex>` | Console / admins | As if the player clicked that story prop or story creature. |
| `storyfaction` | `storyfaction <creature guid hex> <0 enemy \| 1 neutral \| 2 ally>` | Console / admins | A story creature's faction. |
| `storyfire` | `storyfire <prop guid hex> <event id>` | Console / admins | Raises a prop's event (Play Mode). |
| `storylink` | `storylink <source hex> <event> <target hex> <action>` | Console / admins | Adds a Link as the player would (logs the result code). |
| `storyweapons` | `storyweapons <creature guid hex> <1 equipped \| 0 sheathed>` | Console / admins | A story creature's weapon visuals (AnimationSelection 352 / 353, Creatures.StoryWeapons); logs whether anything changed. |
