# Database: World (`lmemu_world_<WORLD_KEY>`)

> Generated by `tools/wiki_reference.py`. Back to [Database Documentation](Database-Documentation).

One per world (Docker: `lmemu_world_main` for the first one). The world's own data: build sites, placed props, chests, vendor stock, prop links and areas. It is created with the same tables as the character database (the same EF Core model and migrations), but only the world tables below are used.

Source: `LandmarkEmulator.Database.Character/Migrations/CharacterContextModelSnapshot.cs`. Code: [LandmarkEmulator.Database.Character](Project-Database-Character).

Tables: [`claim`](#claim), [`claim_permission`](#claim_permission), [`claim_vendor_item`](#claim_vendor_item), [`chest_item`](#chest_item), [`world_prop`](#world_prop), [`world_prop_binding`](#world_prop_binding), [`world_prop_setting`](#world_prop_setting), [`world_area`](#world_area), [`site_template_instance`](#site_template_instance)
