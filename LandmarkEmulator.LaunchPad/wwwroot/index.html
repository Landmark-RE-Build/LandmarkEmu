    Servers

    Add the servers you play on: their address is all you need (ask the server's owner). The server tells LaunchPad the rest, and any patches it needs.

      Patch packs

      The one patch LaunchPad installs is Daybreak's update from the Steam build to 0.695, checked file by file against LaunchPad's own list of the genuine files (SHA-256): nothing else gets into your game. Install it from its .lmpatch file (choose it, or drop it on this window). It only goes on a complete Steam copy of Landmark, and the files it replaces are kept in a compressed backup so it can be undone.

      Daybreak's last build (14 Feb 2017) differs from the January build in Landmark64.exe and the English text (Locale\en_us_data.dat / .dir). LaunchPad has no SHA-256 of those three, so normally a pack with them is refused. With this on, a pack you choose or make yourself may write them checked only by their size and CRC32 against Daybreak's list, which a forged file can match: only use packs you trust. It never applies to a server's update or to any other file.

      Installed (newest first)

        Create update pack

        If you have a 0.695 copy of Landmark, LaunchPad can make the update pack from it, for yourself or for a server. It takes only Daybreak's genuine 0.695 files: every file is checked against LaunchPad's own list of them (SHA-256) first, and the folder is refused if any file is missing or different. The pack contains game files from your own copy, and installs only on a complete Steam copy of Landmark , so it is no use to anyone who doesn't own the game.

        Validate files

        Checks every game file: Steam's original, or the installed patch's version of it. It reports problems; nothing is downloaded or changed.

        Game folder

        LaunchPad works on the folder it is in.

        LaunchPad doesn't download the game: patches only go on a complete Steam install of Landmark . If files are missing or changed, use Steam's "Verify integrity of game files" (Landmark > Properties > Installed Files).

        Options

        Off (the default), LaunchPad writes its recommended values into the game's ClientConfig.ini each time you press PLAY, as always. On, Settings gets a Client settings tab for this game folder: each value LaunchPad changes, what it does, and where you may choose, your own value or none.
