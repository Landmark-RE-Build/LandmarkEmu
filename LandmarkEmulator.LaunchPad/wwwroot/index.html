    Servers

    Add the servers you play on: their address is all you need (ask the server's owner). The server tells LaunchPad the rest, and any patches it needs.

      Patch packs

      The one patch LaunchPad installs is Daybreak's update from the Steam build to the final build, checked file by file against the build's own list: nothing else gets into your game. Install it from its .lmpatch file (choose it, or drop it on this window). It only goes on a complete Steam copy of Landmark, and the files it replaces are kept in a compressed backup so it can be undone.

      Installed (newest first)

        Validate files

        Checks every game file: Steam's original, or the installed patch's version of it. It reports problems; nothing is downloaded or changed.

        Game folder

        LaunchPad works on the folder it is in.

        LaunchPad doesn't download the game: patches only go on a complete Steam install of Landmark . If files are missing or changed, use Steam's "Verify integrity of game files" (Landmark > Properties > Installed Files).
