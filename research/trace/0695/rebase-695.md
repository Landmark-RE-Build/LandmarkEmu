# Rebase of the written traces onto the 0.695 client: verdict per changed / unpaired function

Phase E part 2, agent pe2-rebase, 2026-10-26. Generated by `python re/tools/rebase695.py -w` from
re/out/rebase695.tsv (the comparison) and re/out/rebase695_verdicts.tsv (the verdicts, written by hand after reading
both decompiles of every function). Method and counts: trace/0695/phaseE2-rebase.md. Address map for every cited
function: trace/0695/address-map-589-695.md.

Scope: every function address cited in trace/systems/*.md, trace/architecture/*.md, trace/*.md and
LandmarkEmu/docs/*.md that the trace cites as a **0.589** address (or that is the same address in both builds) and
whose 0.695 partner differs from it (status `changed`: the function or a depth-1 callee differs after the
normalisation of re/out/agent_coverage_e/rcmp.py, beyond struct offsets / constants), or that has no 0.695 partner
(`unpaired`). Addresses cited as 0.695 addresses are already on 0.695 and are listed only in the address map.

Verdict kinds:
- **no server effect**: the change is client-side only (UI data sources, helpers folded, null checks, struct
  offsets, local rendering / physics), with the reason.
- **server effect, server matches**: the change touches what the server sends or must do (packet fields, ids,
  result codes, texts, data table columns, rules) and LandmarkEmu already does the 0.695 thing (file cited).
- **server effect, gap**: the server did not match; fixed in branch local/pe2-rebase (worktree wt-pe2-rebase) or
  written as a new lead in trace/0695/phaseE2-rebase.md.

Recurring patterns (said once here, cited per row):
- **PlayerUpdate sub u8 → u32.** Every PlayerUpdate 0x26 reader reads the sub-opcode as a u32 in 0.695
  (`26 00 ss 00 00 00`); the body readers after the header were compared one by one in coverage-695.md (59 equal
  after the header, 18 identical, the rest checked by hand). The server writes the u32 sub (docs/protocol.md §1.6,
  OpcodeCodecTests). Per-sub body changes are named in their row.
- **Commerce 0x45 subs ≥ 0x30 moved +1** (docs/protocol.md); the server uses the native 0.695 numbers.
- **String helper folded**: 0.695 replaced the inline `IString` + Lua-param code by FUN_142d519b0; the keys are
  unchanged (the strings of both bodies were compared).
- **Local brush effect byte**: 0.695 passes a tool-kind byte (10 / 1 / 5) to the client's own VoxelFarm stamp; the
  server only receives the edited cell (ApplyDiffRequest, unchanged).
